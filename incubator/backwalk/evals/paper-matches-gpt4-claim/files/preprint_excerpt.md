# CurriculumRL: Matching Frontier Model Reasoning at 3B Parameters

**Authors:** Anon et al. · **Preprint:** arXiv:2611.XXXXX (under review)
**Date:** 2026-11-01

## Abstract

Multi-step reasoning in language models has typically required
frontier-scale parameter counts. We introduce CurriculumRL, a
staged-difficulty reinforcement-learning fine-tuning procedure applied
to a 3B base model (Qwen-3B-Instruct), achieving **reasoning
performance competitive with GPT-4 on StepBench-Hard, our new
benchmark for multi-step logical reasoning**. CurriculumRL requires
only 1,200 H100-hours of fine-tuning and runs at ~180 tokens/sec on a
single consumer GPU. We release the model weights and benchmark.

## Introduction

The capability gap between 3B and 400B+ parameter models on reasoning
benchmarks has been widely attributed to emergent properties of scale.
We show that a carefully structured curriculum of reasoning problems,
combined with online RL using an outcome-based reward model, closes
much of this gap without additional parameters.

## Method: CurriculumRL

### Phase 1 — Supervised bootstrap (50k examples)

We generate 50k multi-step reasoning problems by prompting GPT-4 with
seed templates covering: syllogistic reasoning, arithmetic chains,
constraint satisfaction, causal inference, and combinatorial counting.
Each generated problem is verified by GPT-4 against a reference
solution. Verified problems are used for supervised fine-tuning.

### Phase 2 — Curriculum RL (400k steps)

We partition the problem distribution into 5 difficulty tiers (I-V)
based on GPT-4-assigned difficulty labels. Training progresses tier
by tier: models that achieve >70% pass@1 on tier k advance to tier
k+1. The reward model is a GPT-4-class instance that scores candidate
solutions for correctness against generated reference solutions.

### Phase 3 — Mixed-tier polish (40k steps)

A final 40k steps mixes all five tiers in proportion to the inverse of
observed performance (harder-tier examples weighted higher).

## Evaluation: StepBench-Hard

We release **StepBench-Hard**, a benchmark of 2,500 multi-step
reasoning problems constructed to evaluate frontier-level reasoning.
Problems were generated by prompting GPT-4 with instructions to
produce problems "at least as hard as the hardest GSM8K items while
requiring at least 4 distinct reasoning steps." Each problem was
manually reviewed for solvability by a reference GPT-4 trace.

**Evaluation protocol.** Models are scored on StepBench-Hard using
GPT-4 as judge (default GPT-4 Turbo configuration via the public API,
as of August 2026). The judge is prompted with the problem, the
reference solution, and the candidate response, and asked to classify
the candidate as "correct" / "partial" / "incorrect." Pass rate is
the fraction classified "correct."

## Results

### Headline

| Model                     | StepBench-Hard pass@1 | GSM8K pass@1 | MATH pass@1 |
| ------------------------- | --------------------- | ------------ | ----------- |
| GPT-4 (Turbo, default)    | 84.3                  | 92.0         | 50.4        |
| Claude Opus 4             | 86.1                  | 92.5         | 54.2        |
| Qwen-3B-Instruct (base)   | 34.6                  | 68.1         | 23.0        |
| **CurriculumRL-3B (ours)**| **81.7**              | 74.3         | 28.6        |

On StepBench-Hard, CurriculumRL-3B achieves pass rate 81.7, within 3
points of GPT-4 (84.3), narrowing the parameter-efficiency gap by
~96% relative to the base model (34.6 → 81.7).

### Ablations

| Configuration                      | StepBench-Hard |
| ---------------------------------- | -------------- |
| CurriculumRL (full)                | 81.7           |
| No Phase 3 polish                  | 76.8           |
| 3 tiers instead of 5               | 74.1           |
| 7 tiers instead of 5               | 73.8           |
| GPT-4 reward model → Mixtral-8x7B  | 68.2           |
| No curriculum (shuffled tiers)     | 61.4           |
| Supervised-only (no RL)            | 58.3           |

### Generalization

On GSM8K and MATH (not optimized against), CurriculumRL-3B improves
over the base model but does not match GPT-4. We interpret this as
evidence that reasoning capability generalizes but that benchmark
specificity remains.

## Compute

- Phase 1: 24 H100-hours (data generation + SFT)
- Phase 2: 1,100 H100-hours (RL with GPT-4 reward model)
- Phase 3: 80 H100-hours
- **Total: ~1,200 H100-hours** (vs. estimated 10,000+ for a 70B RL
  fine-tune)

## Limitations

We acknowledge that CurriculumRL's reward signal and benchmark both
involve GPT-4, which is also the frontier model we compare against.
We argue this is a weakness shared by most RLHF-derived evaluation
pipelines in the field. We release weights and benchmark publicly to
enable independent evaluation.
